# 产业链研究 — 详细参考

## Phase 1 详细指引：产业链地图

### 提问模板

用户给出主题后，用以下结构化提问做产业链拆解：

> 如果 [宏观趋势] 继续发展，从 [上游] 到 [下游]，整条产业链有哪些关键环节？每个环节目前的供需状态如何？哪些环节产能充裕，哪些是瓶颈？

### Mermaid 地图规范

- 方向：`LR`（从上游到下游）
- 瓶颈环节用 `:::warning` 样式高亮
- 每个节点标注供需状态
- 节点数控制在 8-15 个
- 过多环节时拆成"上游材料"和"中下游应用"两张图

### 信息来源

- 用 `web-access` 搜索："[主题] 产业链 瓶颈 2025/2026"
- 搜索行业研报关键词："[主题] 供需格局"、"[主题] 产能扩张"
- 搜索英文源："[topic] supply chain bottleneck analysis"

## Phase 2 详细指引：瓶颈下钻

### 下钻提问链

沿着产业链的一个环节持续追问：

1. "[环节] 的核心零部件/材料/工艺有哪些？"
2. "哪一段最难扩产？扩产周期多长？"
3. "全球主要供应商有哪些？市占率如何？"
4. "其中 A 股上市的有哪些？代码、市值、主营业务占比？"
5. "这些公司有没有进入 [头部客户] 的供应链？验证进度？"

### 候选公司信息模板

对每个候选公司收集：

- **基础信息**：名称、代码、市值、主营构成
- **瓶颈相关度**：核心产品在瓶颈环节的位置
- **市占率**：全球和国内市占率
- **客户结构**：前五大客户、是否绑定头部
- **产能情况**：现有产能、在建产能、预计投产时间
- **近期催化**：新订单、新产线、新客户验证

## Phase 3 详细指引：交叉验证

### 五维验证清单

#### 1. 瓶颈持续性

- 这个瓶颈会在未来 1-2 年内被技术替代吗？
- 有没有替代技术路线正在研发？进展到什么阶段？
- 如果下游需求放缓，瓶颈还成立吗？
- 判断标准：瓶颈越难被绕过、持续时间越长 → 越值得投资

#### 2. 竞争壁垒

- 壁垒来源是什么？（技术 know-how / 客户认证周期 / 设备投入 / 专利）
- 竞争对手追上来需要多久？（< 1年 = 低壁垒 / 1-3年 = 中 / > 3年 = 高）
- 下游客户的转换成本高吗？
- 判断标准：壁垒越高、客户黏性越强 → 越安全

#### 3. 收入兑现

- 从签订单/通过验证到确认收入，需要多长时间？
- 当前收入结构中，瓶颈相关业务占多少？
- 未来 2-4 个季度有没有明确的收入增长催化？
- 判断标准：收入兑现越近、占比越高 → 越有短期弹性

#### 4. 风险因素

- **减持/增发**：大股东近期有减持计划吗？有没有定增/配股稀释？
- **地缘风险**：产品是否涉及出口管制？客户是否涉及制裁？
- **管理层**：管理层是否有诚信问题？历史上有没有坑过投资者？
- **依赖风险**：是否过度依赖单一客户或单一产品？
- 判断标准：任一维度有重大红旗 → 直接标注为"暂时回避"

#### 5. 估值合理性

- 当前股价隐含了多少年的增长预期？（用 PEG 或 DCF 简单估算）
- 如果增速不达预期（比如打五折），下行空间有多大？
- 同行业可比公司的估值中位数是多少？
- 判断标准：估值已透支 2 年以上增长 → 等回调再关注

### 综合评级

根据五维结果给出三档评级：

- **强烈关注** — 瓶颈持续 + 壁垒高 + 收入即将兑现 + 无重大风险 + 估值合理
- **值得跟踪** — 多数维度正面但有 1-2 个待确认项
- **暂时回避** — 有重大红旗或估值严重透支

## Phase 4 详细指引：市场阶段判断

### 阶段识别信号

**阶段 1（分歧期）**
- 信号：行业新闻零散，券商覆盖少，社交媒体讨论不多
- 股价特征：龙头公司股价刚从底部开始上涨
- 策略：买龙头——第一反应能想到的那家公司（确定性最高，流动性最好）

**阶段 2（共识期）**
- 信号：券商密集发研报，行业会议增多，龙头股价已涨 50-100%
- 股价特征：资金开始从龙头溢出到二线
- 策略：找产业链中供需错配最大的细分环节，弹性最大

**阶段 3（压制期）**
- 信号：龙头估值到历史高位，市场开始质疑增速可持续性
- 股价特征：龙头高位震荡或回调，但产业趋势仍在
- 策略：只看收入弹性尚未兑现的二线标的，或有新业务催化的公司

**阶段 4（泡沫期）**
- 信号：出租车司机都在聊这个行业，概念股鸡犬升天
- 股价特征：涨幅与基本面严重脱节
- 策略：回避。如果已持有，考虑逐步减仓

### 判断方法

结合以下信息源判断当前阶段：
- 券商研报数量和基调（看多/看空比例）
- 社交媒体讨论热度（雪球、微博、财经公众号）
- 龙头股票估值分位数（历史 PE/PB 百分位）
- 近期有无行业 ETF 资金大幅流入
