# Industry Structure First

Logic 层写任何公司分析之前，必须先用 2–3 段把"这个公司所在的行业是什么形状"讲清楚. 这一步决定了后面所有论断能不能自己站住.

## 为什么必须先写行业

默认陷阱：跳过行业直接讲公司，LLM 会不自觉地把这家公司的特征当作行业的特征——"研发投入高"、"客户集中"、"毛利率下滑"，读者没有坐标系，无法判断这些特征是行业常态还是公司异常. 先写行业等于先给读者校准了参照系.

参照《晚点》范式：讲卧龙之前，先用 5 段讲电驱动行业——传统通用 vs 新能源车 vs 新兴应用，每块的需求特征、技术壁垒、利润结构、集中度. 有了这张地图，"卧龙 90% 业务在传统领域"这句话的含义才能自动浮出来.

## 行业结构分析的 5 个维度

每个行业最少回答这 5 个问题. 不用全部写进正文，但必须想过.

### 1. 行业边界与细分

- 这个行业叫什么？它把什么转化成什么？（"电驱动系统把电能转化为机械能"）
- 细分几块？每块的下游客户是谁？
- 哪块**规模最大**？哪块**增速最快**？哪块**利润率最高**？这三个回答常常不是同一块——这个错位就是行业动力学的核心.

### 2. 市场规模与增速

- 总规模（亿元 / 亿美元）+ 3–5 年 CAGR.
- 每个细分的规模拆分.
- 增量主要来自哪块（新开行业 / 存量替代 / 进口替代）.

### 3. 技术壁垒梯度

- 哪些细分是"技术成熟、供给充足、需求标准化"（低壁垒 → 格局分散、利润稳定但低）？
- 哪些细分是"性能、能耗、材质极端要求"（高壁垒 → 集中度上升、潜在溢价）？
- 壁垒来自哪里：专利、工艺、客户深度认证、规模效应、牌照？

### 4. 竞争格局

- TOP5 合计市占率（判断分散还是集中的第一眼指标）.
- 领先者是否在**持续扩大领先优势**（赢家通吃）还是**被追赶者蚕食**（打不出护城河）？
- 有没有**错位竞争者**——从相邻行业切过来的玩家（比如汇川从工控系统切具身机器人，带的是集成商基因而非单纯零部件基因）.

### 5. 周期性与驱动变量

- 这是**成长行业**（随技术扩散）、**周期行业**（跟随宏观 Capex）、还是**成熟行业**（增速 ≈ GDP）？
- 需求端的关键变量是什么？下游某个单一市场是否决定了这个行业的命运（比如激光设备吃制造业 Capex 周期；PCB 设备吃 AI 服务器 Capex）？
- 供给端近 3 年有没有技术代际切换？（燃油车 → 新能源车、4G → 5G 这类）

## 结构性归因的模板句

写行业段时，多用"因为 X，所以 Y"的归因句. 示例：

> 在这类细分场景中，由于技术成熟、供给充足、需求标准化等因素，使行业格局长期分散，头部参与者之间份额差距有限，利润结构相对稳定.
>
> 这导致这些市场的竞争格局比较分散，TOP5 公司合计的市场占有率均在 20% 以内，也就意味着这一领域的并购只能带来规模的增长，却很难持续释放利润杠杆.

这种句子结构：**特征 → 导致 → 市场行为 → 意味着什么**. 有了这个结构，后面讲"公司 A 在这个领域做了 N 次并购"时，读者立刻知道这些并购为什么不产生利润弹性.

## 把公司嵌入行业地图

行业段讲完后，**用一到两句把目标公司放到地图上的坐标里**. 示例：

> 作为这个行业的头部公司，卧龙电驱约 90% 的业务收入来自于传统的防爆、工业、及暖通领域，虽然公司已经处在这些领域全球 TOP5 的阵列，但其近年来并没能成功切入到新能源车电驱动市场（其该业务收入占比不足 5%），也就没能分得该市场增长的红利.

一句话完成了：**公司位置（传统领域 TOP5）+ 错过的机会（新能源车切入失败）+ 后果（没分到红利）**. 这是行业段和公司段之间的"接头"句，写好了整篇都通. 写不出来意味着前面的行业结构没想清楚.

## 常见失败模式

### ❌ 把公司描述当行业描述

"激光设备行业是一个高技术、高研发、竞争激烈的行业"——这是 LLM 的默认回退. 任何行业都可以这样写. 没信息量.

### ❌ 只写行业规模不写结构

"市场规模 500 亿，CAGR 15%"然后就进入公司部分——读者还是没地图. 必须拆细分、讲壁垒梯度、讲集中度.

### ❌ 归因到"宏观趋势"就停

"受益于 AI 浪潮"是万能解释词，不是分析. 要继续推到：**AI 浪潮里哪个具体环节产生了设备需求**、**这个设备需求的规模对这家公司意味着增量多少**、**这个增量的持续性取决于什么宏观变量**.

### ❌ 把竞争对手列表当做行业分析

"主要竞争对手：A, B, C, D" 不是行业分析，是目录. 必须回答：**A, B, C, D 之间的真实关系是什么**——谁在抢谁的份额、谁定义了技术路线、谁在做另一种 business model 对抗主流.

## 对应到 Logic 层写作顺序

Logic 子 agent 产出时建议按这个顺序：

1. 行业边界 + 细分（1 段，约 200–300 字）
2. 行业规模 + 集中度 + 壁垒梯度（1–2 段，约 400–600 字）
3. 结构性归因（为什么这个行业是现在这个样子，1 段）
4. **公司定位接头句**（1–2 句，承上启下）
5. 公司收入机制 + 细分业务拆分（1–2 段）
6. 护城河分析（用中文讲，不用 moat 类型名做 header）
7. **配对比较**（必做，1–2 段）
8. 量化压力测试（可选但推荐）

总长大约 3000–4500 字（Standard 深度下的 Logic 层）. 不要省略行业段.
