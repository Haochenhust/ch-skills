# Report Template — Claim-Style Headers

不是填空表。是一个起始形状，根据公司实际的故事来变形.

核心原则：**标题必须是一句带动词的完整论断**，段落展开去证明这个论断. 下面给的是句式范例，不是复制粘贴的目标.

## 推荐骨架

```
# <公司名>：<一句话核心论断>
例如：大族激光：老树发新芽，但树还是那棵老树

<开场 1 段：或者一个直击核心的问句，或者一个反直觉的数字陈述。不做执行摘要，不做"本文将讨论"。>

## <一句话讲清行业结构的 claim>
例如：激光设备是一个格局分散、利润温和的行业，真正能打出利润弹性的只有新兴应用端

<行业段：3–5 段。先讲行业边界和细分，再讲每个细分的壁垒和集中度，最后把目标公司放到地图上。>

## <一句话讲公司怎么走到今天的 claim>
例如：三次踩对浪潮，中间夹一次把信誉打穿的危机

<Story 段：Mature 公司以"几个决定命运的分叉"为主，不需要场景化细节；Early/Growth 公司可以场景化。3–4 段。>

## <一句话讲商业模式为什么是这样的 claim>
例如：六个下游分散，但没有一块绝对赢

<Logic 核心段：收入机制 → 细分业务拆 → 成本结构 → 客户集中度。带具体数字。3–4 段。>

## <一句话评估护城河强弱的 claim>
例如：没有教科书里的硬护城河，撑得住的是规模加工程化积累的弱组合

<护城河段：用中文描述护城河本质 + 证据 + 失败模式。不要用 "moat type 1/2/3" 做小标题。1–2 段。>

## <一句话给出关键配对比较的 claim>
例如：对比联合动力的成功，卧龙的失败不冤

<配对比较段：强制。选 1 个最能说明问题的对手做深度对比。必须落到具体的战略动作差异。2–3 段。>

（可选）### <一句话讲财务质量判断的 claim>（Scenario D 专用）
例如：+106.5% 净利暴涨是账面烟花，扣非 -4.39% 才是主业真相

<财务段：只讲四步读法里最关键的 1–2 个判断，不做全面 10-K 复述。200–400 字。>

## <一句话讲未来 3–5 年关键赌注的 claim>
例如：2026 年的 AI PCB 订单兑现是命门年

<Judgment 的 lever 段：2–3 个可证伪的杠杆。每个给出具体的证伪阈值。2–3 段。>

## <一句话亮明立场的 claim>
例如：我不买，但我等 PCB 持续性加老板质押率双降

<Judgment 的立场段：明确的"我会/不会/等 + 触发条件"。理由可攻击。1–2 段。>

<结尾：用一个指向未来具体动作的句子收尾，不要 TL;DR，不要"综上所述"。>
```

## 标题写作的 3 个规则

1. **必须是完整的一句话，带主语+谓语**. 不是"业务模式"，是"业务模式决定它只能做中等生意".
2. **应该可被读者证伪**. 如果读者说"我不同意你这个标题"，你应能精确追问 TA 不同意哪部分——意味着标题本身承载了你的立场.
3. **避免冒号堆标签式写法**. 不写"Logic：六个下游分散"，写"六个下游分散，但没有一块绝对赢".

## 开场句的可选模式

不要每次都用"电影式开场". 根据公司类型选：

- **矛盾陈述**：公司对外讲 A 故事，数字讲 B 故事——然后展开解释.
- **直接问句**：为什么市场还相信一家新能源车业务已经失败的公司会在具身机器人上成功？
- **反常数字**：过去 5 年利润 CAGR -3%，但 PE 从 15 倍涨到了 60 倍. 市场在定价什么？
- **行业定位句**：在一个格局长期分散的行业里，X 公司凭什么做到了 TOP 5？
- **场景式**（仅对有名创始人或戏剧性决策时刻）：40 万港元定金，3 个月独自做出第一台机器——这是 1995 年的某一天.

## 下笔前检查

- [ ] 开场没用"X 公司成立于 YYYY 年"这种懒惰句.
- [ ] 至少 2 段行业结构分析在公司段之前.
- [ ] 至少 1 个配对比较.
- [ ] 每个章节小标题都是完整论断句（自我检查：加"我不同意这个标题"能追问吗？）.
- [ ] 全文没有 moat / process power / capital allocation / unit economics 等自造夹杂词.
- [ ] 判断段落有明确立场，不骑墙.
- [ ] 没有"综上所述"/"In conclusion"的结尾段.
- [ ] 字数落在声明的配额内（Standard 7000–10000 字）.
- [ ] 不确定信息有 `[推测]` 标签.
